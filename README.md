# Atividade de gestao de Projeto

## Integrante: 
- Francisco Henrique

## Propósito do Projeto
- Aplicar os conceitos de controle de versão utilizando o Git. <br/>
- Simular o processo de planejamento e execução de um release de software. <br/>
- Praticar o uso de branches, commits, pull requests, tags e releases.

## Plano de Releases Previsto
- **Primeiro Release:** Tela de login construída e página de aviso "em construção" (working.html).
- **Segundo Release:** Página de login a chamar a página do administrador (pg001.html) sem validar se os campos de login e senha foram preenchidos.
- **Terceiro Release:** Funcionamento completo: se deixar usuário em branco (só valida este campo) mostra página de erro. Ao digitar “admin” exibe a tela do administrador, qualquer outro conteúdo em usuário mostra a página do operador.
